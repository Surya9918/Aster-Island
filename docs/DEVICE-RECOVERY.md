# Volume and brightness HUD recovery

The headphone feature introduced a managed COM coclass collision: endpoint discovery and volume control each declared their own DeviceEnumerator coclass with the same native CLSID. When both modules ran in one process, volume activation could throw InvalidCastException. The standalone platform probe missed this because it exercised volume without first initializing headphone discovery. Both modules now share one generic native activation factory. The native audio probe now enumerates endpoints, subscribes to device changes, reads volume and attaches the volume callback in the same process.

The desktop integration now initializes independently from slower media/radio startup. Device readiness is refreshed asynchronously every two seconds; event subscriptions still provide the primary low-latency updates. Missing subscriptions retry, output-device changes rebind the volume listener, and resume recreates subscriptions. Successful reads restore key readiness after a failure instead of leaving controls disabled for the rest of the session. Reading initial values does not produce a fake change popup. Explicit intercepted key presses show their HUD even at a capped level.

Validation: native endpoint discovery + device subscription + volume read + volume subscription all passed together. Live device test passed audio/brightness readiness recovery, external volume callback, intercepted volume key, actual volume change, volume HUD, actual brightness change, brightness callback, brightness HUD, intercepted brightness shortcut and shortcut HUD. Initial volume/mute/brightness were restored in a finally block and verified. The 109-test suite passes. Physical firmware brightness-key interception remains dependent on the laptop key behavior and any learned key mapping; Ctrl+Alt+Up/Down is the validated shortcut. No global Windows brightness-flyout suppression is claimed.

The eye pair, monochrome theme, night preference, notification permission and disabled taskbar feature are preserved.
